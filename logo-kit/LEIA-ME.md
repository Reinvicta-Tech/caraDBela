# CaraDBela: kit do logo (v2.0, 2026-11-25)

Refresh fiel: a mesma cara que pisca o olho, com geometria exata.

| Ficheiro | Uso |
|---|---|
| `caradbela-horizontal-{color,black,white,azul}.svg` | Logo principal |
| `caradbela-horizontal-reversed.svg` | Fundos escuros, com selo |
| `caradbela-stacked-*.svg` | Formatos quadrados |
| `caradbela-symbol-*.svg` / `caradbela-symbol-small-*.svg` | Símbolo / abaixo de 48 px |
| `caradbela-wordmark-*.svg` | Só o nome |
| `caradbela-selo*.svg`, `caradbela-app-icon.svg` | Sobre cor ou imagem, ícone de app |
| `caradbela-selo-atenta.svg` | Expressão para poucos alertas médios na interface. Não é o logo |
| `caradbela-selo-aflita.svg` | Expressão para alertas altos ou muitos alertas na interface. Não é o logo |
| `variants/` | PNG |
| `web/` | favicon, ícones, `site.webmanifest`, `head-snippet.html` |
| `caradbela-guia.html` | Guia de utilização |
| `caradbela-apresentacao.html`, `slides/` | Apresentação com aplicações |
| `src/build.py` | Gera todos os masters |
| `assets/caradbela-original.svg` | Logo antigo, só para arquivo |

## Construção

- Símbolo em 256×256. Aro R104/r88, aberto 30° de cada lado da cruz; ondas em arcos exatos de 90°; boca em D deitado.
- A versão branca tem o traço 1 unidade mais fino de cada lado, porque o branco parece mais grosso em fundo escuro.
- Símbolo pequeno: a mesma cara, com ondas mais grossas e menos curvas, e feições maiores.
- Ícone de aplicação: símbolo completo, a cores, em fundo branco. Favicon: selo pequeno.
- Nome: altura 72, hastes 14, barras 13, tudo em contornos, sem fontes. DB a vermelho, como no original.
